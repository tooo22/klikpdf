# Google Antigravity Guide & Reference Specialist (agy-2)

Use this skill whenever the user calls `agy-2` or seeks reference, commands, and guidance on using the Google Antigravity ecosystem.

---

## 1. Antigravity Ecosystem Cheat Sheet

### A. Antigravity CLI (`agy`)
* **Memulai Sesi CLI**: `agy`
* **Melihat Opsi & Flags**: `agy --help`
* **Keluar dari CLI**: Tekan `Ctrl+D` dua kali atau ketik `/exit` / `/quit`
* **File Pengaturan CLI**: `~/.gemini/antigravity-cli/settings.json`

### B. Slash Commands Populer
* `/goal`: Menjalankan misi panjang tanpa henti sampai target tuntas 100%.
* `/schedule`: Menjadwalkan pengingat atau tugas periodik (cron).
* `/browser`: Menavigasi web interaktif dan inspeksi elemen web.
* `/plan`: Menyusun rencana kerja bertahap untuk tugas arsitektur rumit.
* `/grill-me`: Wawancara interaktif untuk memvalidasi kebutuhan desain arsitektur.
* `/boost`: Mengaktifkan analisis mendalam & multi-sudut pandang.
* `/teamwork-preview`: Orkestrasi tim sub-agent otonom yang bekerja bersama.

### C. Antigravity 2.0 & IDE Interface
* **Sidebar Chat Panels**: Ruang percakapan utama dengan agen AI.
* **Canvas / Inline Code Lens**: Refactoring dan peninjauan kode langsung di editor.
* **HTML Auxiliary Pane**: Menampilkan Subagents aktif, Background Tasks, Artifacts, dan Terminals.

### D. Antigravity Python SDK
* Repositori resmi: `https://github.com/google-antigravity/antigravity-sdk-python`
* Digunakan untuk leasing agent secara terprogram, orkestrasi sub-agent mandiri, dan integrasi custom tools.
