# Antigravity Profile Pro 2 (agy-2)

Profil ini dikonfigurasi untuk **Akun Pro 2**.

## Penggunaan di Terminal
* Jalankan di PowerShell: `agy-2`
* Cek status profil: `agy-status`
* Simpan sesi saat ini ke slot 2: `agy-save 2`

## Cara Setup Pertama Kali
1. Jalankan `agy-logout`
2. Jalankan `agy` dan login dengan akun Pro ke-2 di browser.
3. Setelah masuk CLI, tekan `Ctrl+D` dua kali untuk keluar.
4. Jalankan `agy-save 2`.
5. Sekarang `agy-2` siap digunakan kapan saja!
